# RCA 리포트 마스킹 규칙

리포트를 저장하기 전에 본문 · 표 · 발췌 · 명령 예시 전체에 적용한다.

| 대상 | 처리 |
|---|---|
| IP 주소 | 구분이 필요 없으면 `<IP>`로 바꾼다. 구분이 필요하면 역할 별칭으로 바꾼다(서버: `API-1`, `API-2`, 클라이언트: `교사단말A`, `교사단말B` 등). 같은 IP는 리포트 전체에서 같은 별칭을 쓴다 |
| 이메일 | `<EMAIL>`로 바꾼다. 도메인도 남기지 않는다 |
| 학생 식별자 | 등장 순서대로 `학생A`, `학생B`로 바꾼다. 명령 예시에는 `<학생 식별자>`처럼 자리표시자를 쓴다 |
| 토큰 · 세션 ID · API 키 | `<TOKEN>`으로 바꾼다. 앞뒤 일부도 남기지 않는다 |
| 비밀번호 · 접속 문자열 | `<PASSWORD>`로 바꾼다. 접속 문자열은 호스트 · 계정 · 비밀번호를 모두 가린다 |

- 별칭은 리포트 안에서만 일관되게 쓰고, 원문과 별칭의 대응표는 어떤 파일로도 남기지 않는다.
- 저장 후 리포트에 IP · 이메일 · 토큰 형태의 문자열이 남았는지 `grep`으로 다시 확인한다.
- 리포트 끝에 적용 결과를 적는다. 예: `마스킹 적용: IP 주소 11건(역할 별칭 4종), 이메일 0건, 학생 식별자 2건(별칭 2명), 토큰 · 세션 ID · API 키 0건, 비밀번호 · 접속 문자열 0건`
